# TradScale Telegram Bot

ربات تلگرام آموزشی و معاملاتی TradScale.

## ✨ قابلیت‌ها

- 📊 تحلیل‌ها (دسته‌بندی‌شده، قابل مدیریت توسط ادمین)
- 🎓 آموزش‌ها (دسته‌بندی‌شده، قابل مدیریت توسط ادمین)
- 📝 درخواست تحلیل (دوسویه با استاد)
- 💬 ارتباط با استاد (Reply-based)
- 🔗 لینک کانال، گروه و یوتیوب
- 📈 Risk Calculator
- 🏆 Prop Challenge Manager
- 📔 Trading Journal
- 🧠 Psychology Check
- 🤖 AI Assistant (اختیاری)
- 🔧 پنل مدیریت با `/admin`

## 🚀 استقرار روی Render

### Environment Variables
| کلید | مقدار |
|---|---|
| `BOT_TOKEN` | توکن از @BotFather |
| `ADMIN_CHAT_ID` | آیدی عددی ادمین |
| `OPENAI_API_KEY` | (اختیاری) |

### Render Settings
- **Environment:** Python 3
- **Build Command:** `pip install -r requirements.txt`
- **Start Command:** `python bot.py`
- **Health Check Path:** `/health`
